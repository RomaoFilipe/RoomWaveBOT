# RoomWave

Bot de pedidos de música para IMVU, com API, fila PostgreSQL, AutoDJ e transmissão
através de FFmpeg, Liquidsoap e Icecast.

O desenvolvimento atual liga a pesquisa YouTube / YouTube Music ao Audio Engine.
Consulta [a integração, configuração e diagnóstico YouTube](docs/youtube.md) para
o estado validado e os passos de ativação.
